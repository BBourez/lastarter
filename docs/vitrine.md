# Site vitrine (hors périmètre produit)

LaStarter dispose d'un site vitrine marketing, publié sur Framer :
**https://sincere-project-292658.framer.app**.

Il vit **en dehors de ce dépôt** : aucun lien technique avec le produit
(pas de build, pas de données partagées) — ce dépôt contient uniquement le
produit (catalogue, CLI, compose, docs).

Éléments d'identité alignés : rebranding orange LaStarter (`#ff6b35`),
logo texte « La**Starter** », pages accueil/fonctionnalités FR avec
déclinaisons `/en`, blog (4 articles), pricing B2B (Open Source 0 € ·
Sur vos serveurs · Clé en main), sélecteur de langue (20 locales via
Framer Localization).
